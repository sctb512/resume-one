Changes by Resume One contributors, 2026:
Executable Node.js/HTML/CSS was manually reconstructed as bounded declarative
data. The light slab-serif print typography, gray palette, right contact lane,
main identity/summary and compact sidebar keyword layout are retained.
This is an adapted print composition, not a pixel-identical web port.

Explicit differences from the original:
- Name and role stack rather than sharing a baseline; the role uses body size.
- Standard translated section labels replace original uppercase/custom labels.
- Resume JSON module order is retained inside each lane, rather than imposing
  the original default education-before-work order on the user's data.
- Item heading/details are semantic, not independently styled inline fragments;
  italic descriptions and special first-word italics are not reproduced.
- Contact values are plain selectable text without decorative icons or labels.
- Keyword chips use the renderer's bounded accessible tint and spacing, not
  arbitrary CSS radius, ghostly background and print-specific em units.
- No portrait, remote image/font request, custom CSS, or meta.rickosborne
  overrides are executed. All source JSON extensions are preserved untouched.
- A4 has explicit 14 mm margins; original browser print margins were variable.
  Chinese text falls back explicitly to bundled Noto Sans SC. Word owns DOCX
  wrapping/pagination; it can differ from the measured PDF and desktop preview.
