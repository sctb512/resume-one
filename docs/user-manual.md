# Resume One 用户手册

点击应用本地或在线主题后，可在预览工作区用 `⌘Z` / `Ctrl+Z` 撤销、`⌘⇧Z` / `Ctrl+Shift+Z` 重做，与内容操作按发生顺序回退。悬停试穿、再次点击同一主题不产生历史记录；回退只切换外观，不修改简历 JSON，也不重新下载文件。JSON 输入框内的撤销仍用于源码文本。输入法正在组合文字时不会切换视图。

“打开”菜单和系统“文件”菜单均提供“新建简历”（`⌘N` / `Ctrl+N`）。新建保留当前主题和工作目录，进入预览并展开基本信息表单，JSON 初始只有空的 `basics` 对象，不带示例姓名、样式或应用元数据；按保存时再选择文件路径，不自动创建或覆盖文件。当前有未保存编辑或恢复草稿时，先询问是否丢弃；取消保留原输入和草稿。

窗口宽度至少 1280 时显示两侧栏；1024–1279 时通过顶栏“主题”打开主题抽屉，右栏不变；720–1023 时“主题”“模块”分别打开对应抽屉，同时只打开一个。点击遮罩或按 Esc 收起。选定模块后会收起抽屉，方便选择文档插入点；先点文档 `+` 时会自动打开模块抽屉。JSON 模式不显示主题入口，仍能打开模块抽屉。抽屉不会重排文档或影响导出。系统启用减少动态效果时，切换直接完成，不执行平移动画。

JSON 有错误时，预览明确标明正在显示上次有效内容，结构增删暂时禁用；返回 JSON 修复后自动恢复。主题悬停以细线区分，已应用主题使用淡色底和侧标记。顶栏文件、打开、导出与抽屉按钮支持 Tab、Enter/空格操作。

桌面界面沿用 v3 设计的朱印品牌、衬线栏标题和细线列表：顶栏显示文件与保存状态，右侧提供打开、导出；左侧主题用当前简历的第一页生成本机缩略图，悬停停留约 160 毫秒试穿，点击应用。右侧模块采用统一图标与细线列表，仍保留所有增删入口。纸张随窗口等比适配，不改变导出的换行和分页；宽表单的普通字段分两列，长描述通栏，窄表单自动单列。

右侧模块栏的新增入口以已选主题声明的 `modules` 为准。简历中已经存在的标准模块仍保留入口供编辑，切换主题不会删除内容。鼠标悬停试穿其他主题时，右侧模块范围不变；点击应用主题后才更新，并清除尚未完成的插入选择。

预览内容编辑：在基本信息或某个条目上停留约 180 毫秒，或直接点击，可打开文档宽度内的表单；Tab 聚焦内容后按 Enter 也可展开，Esc 或表单右上角关闭。表单浮在正文上方，不占用排版高度。当前支持标准普通文本字段，以及成果要点、课程、关键词和项目角色列表。列表内的 `+`、`−` 可在指定位置增删，新增后焦点进入新输入框；每次增删可独立撤销。基本信息表单也支持地址字段和社交账号的逐项编辑、增删；聚焦下方输入框时会自动滚入表单可视范围。输入同步到内存 JSON 和恢复草稿；清空字段会移除该键。邮箱、日期等暂时无效的输入会保留并提示，修复前不能保存或导出。移出纸张且输入框未聚焦时收起；有输入焦点时保持打开。收起后按撤销可回退整次表单编辑，重做可恢复；字段内仍支持正常文本撤销。

状态：产品正在开发，当前没有正式桌面安装包。源码已支持本地文件/目录打开、预览、原生 JSON 编辑、四种桌面导出、本地主题目录和多来源在线主题浏览：左侧初始显示 20 套本地主题，悬停临时预览、点击选中；中央渲染当前 JSON Resume 或显示源码，右侧始终显示模块及条目数。预览页现可增删标准模块与条目，并撤销、重做；标准文本字段可通过悬停表单编辑。启动方式为 `cargo run -p resume-one-app`，也可附加一个 JSON 文件或目录路径。macOS 开发应用包可用 `bash packaging/macos/bundle.sh debug` 构建。正式默认 GitHub 源和完整主题排版尚未交付。

已实现的打开操作：点击右上角“打开”，选择“打开 JSON”或“打开目录”；macOS 快捷键分别为 `⌘O`、`⌘⇧O`，Windows 为 `Ctrl+O`、`Ctrl+Shift+O`。打开目录只列出该目录第一层的普通 `.json` 文件（扩展名不区分大小写，不递归扫描，不跟随目录内符号链接），从顶栏文件名或 `⌘P`/`Ctrl+P` 打开切换器，用上下方向键和 Enter 选择，Esc 或点外部收起。“刷新”重新扫描目录，目录为空时会明确显示空状态；取消或读取失败保留当前简历与主题。

打开文件或目录不会修改原文件，也不会把主题信息写入 JSON。无文件时显示“示例简历 · 未保存”。语法或 Schema 无效但属于 UTF-8、且不超过 16 MiB 的 JSON 文件会直接进入源码编辑器，原字节保持不变；修复到有效状态后，预览才显示该文件的内容，保存前磁盘文件不变。无法解码的非 UTF-8 文件和超限文件会明确拒绝。成功打开或保存的文件会进入最近列表（最多 12 项）；点击顶栏文件名或按 `⌘P` / `Ctrl+P` 可在当前目录文件及其他最近文件间切换。上次打开的目录在重启后恢复为切换范围，但启动仍直接显示预览，不自动读取最近简历正文或弹出文件列表。路径只保存在本机应用设置中，不写入简历；失效文件会从重启后的最近列表中隐藏。

应用启动进入预览。按 `⌘/`（macOS）或 `Ctrl+/`（Windows）切换预览和 JSON 编辑，也可从系统“视图”菜单触发。切换约 360 毫秒：左侧主题轨道被中央工作区挤出或从左拉入，旧视图保留到末段再交接；快速反向切换从当前空间和透明度继续，顶栏和右侧模块栏始终保持原位。JSON 编辑器显示格式化后的副本，不会仅因进入编辑器就改写原始文件。编辑器支持行号、主题语法色、软换行、回车缩进，以及在字符串外输入 `{`、`[`、`"` 时自动补全成对符号；单次撤销可同时移除补全的一对符号。直接输入实时校验 Schema；有错误时底部显示原因和路径，保留最近一次有效预览，修复前不能保存。编辑区无标题条或格式化按钮，没有状态时不占用底部空栏。`Ctrl+F` 格式化 JSON；`⌘Z`/`Ctrl+Z` 撤销，格式化也可撤销。搜索为 `⌘⇧F`/`Ctrl+Shift+F`。

`⌘S`/`Ctrl+S` 保存已有文件；未命名示例会弹出“另存为”。`⌘⇧S`/`Ctrl+Shift+S` 另存为新 `.json` 文件。保存使用文件版本检查：如果磁盘文件在打开后被外部修改，不会静默覆盖。无效 JSON/Schema 内容不能保存。编辑中的内容在应用私有数据目录另存恢复草稿；重新打开同一文件时可选择恢复，恢复后仍遵守原始文件版本检查。切换文件或关闭窗口时，未保存内容会先提示，选择丢弃会删除相应恢复草稿。

预览中，鼠标靠近模块之间或条目之间的插入位置会显示 `+`；悬停已有模块标题或条目会显示对应的 `−`。这些控件不会因悬停而挤动正文。点击模块间 `+` 后，正文淡出，右侧可添加的标准模块保持清晰，已存在的模块变淡且不能重复添加；也可先在右侧点选尚未存在的模块，再点击纸张上的目标 `+`，此时正文及右侧其他模块变淡，仅模块插入点保持可操作。点击右侧已有的条目型模块，则仅显示该模块的条目插入点。聚焦淡入淡出约 140 毫秒，右栏不移动；聚焦期间不会触发正文编辑表单。Esc、再次点击已选模块或切换源码可取消待插入状态，取消不修改内容、不占用撤销记录。结构操作只修改当前内存中的 JSON，并保留扩展字段；按 `⌘Z`/`Ctrl+Z` 撤销、`⌘⇧Z`/`Ctrl+Shift+Z` 重做，保存前不会改写磁盘。空模块保留在右侧栏，选中后可添加第一条内容；切换至 JSON 编辑可看到同步后的结构。JSON 视图的固定右栏现提供模块 `+`/`−`，已有模块的 `+` 会在末尾添加条目；点击已有模块可展开条目列表，在指定位置插入或删除条目。源码编辑器中的这些操作可用文本撤销恢复，撤销回原文件后未保存状态也会清除。JSON 代码行旁也提供 `+`/`−`：标准模块的键名行可移除模块，条目开始处可插入或移除该项，列表闭合处可追加条目；模块间 `+` 与固定右栏双向联动，Esc 取消并恢复文本焦点。控件留在独立窄栏，不挤动文字；软换行、滚动和缩放后仍按实际字符位置对齐。若多个目标处于同一视觉行，点击会打开带名称的操作菜单。每次结构编辑可独立撤销，快速连续点击也不合并；撤销后新编辑会清除旧重做分支。语法/Schema 无效或输入法组合输入期间，不显示行旁操作；修复或提交输入后恢复。顶层键重复或结构锚点超过 50,000 时不提供行旁控件，但保留原文供源码修复。

应用仅使用一个当前本地主题目录。首次运行会在系统本地应用数据目录的 `Resume One/themes` 安装 20 套默认声明式主题文件；同名已有文件不会被覆盖。点击左侧“管理”，或在系统“主题”菜单选择“管理主题…”，可更换目录或恢复默认目录，选择后会把缺失的默认主题文件复制到新位置，并载入该目录根部的 `*.theme.json` 及一级子目录中的 `theme.json`。不合规文件会被跳过，原因在管理页查看；不同文件允许有相同 ID，选择按文件身份区分。右键本地主题可在文件管理器中定位对应 JSON 文件。目录设置跨重启保存，切换或重置不会删除旧目录文件。应用不提供云同步；若把简历或主题目录放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

主题管理可用 `⌘,`（macOS）或 `Ctrl+,`（Windows）打开，Esc 或“完成”关闭；打开时工作区和右栏不移动。在线来源只在管理内添加、修改、移除，列表旁没有添加源的 `+`。每个来源填写公开 GitHub 的 `owner/repository`、分支/标签/commit（默认 `main`）和清单路径（默认 `themes/index.json`）；最多 16 个，不允许重复配置。填写草稿不会联网，点击“添加来源”“保存修改”或在输入框内按 Enter 才持久化；取消修改或直接关闭不保存表单草稿。移除来源只删除该配置，不删除本地主题文件。来源与目录设置跨重启保存，互不覆盖；设置文件损坏时会保留原文件并提示，拒绝覆盖。若当前已在浏览在线列表，保存来源变更会重新加载当前来源。暂未提供正式默认 GitHub 仓库。

左侧可切换“本地 / 在线”，在线列表上方点仓库名称选择来源（同一来源可重新选择以刷新）。两类主题均用当前 JSON Resume 在中央实时渲染，不下载在线预览图片；悬停仅试穿，点击且通过校验后才应用。来源和 commit 不同的同名主题相互独立；切换浏览来源、本地列表或本地目录不会清除已应用的在线主题。在线列表预取可视区域附近 20 个主题，悬停优先，最多 3 个后台任务；旧响应不会覆盖新的悬停或选择。网络失败时尝试有效缓存，诊断在管理页查看。未就绪时保留已有有效画面，不显示逐主题提示。右键在线主题选择“下载到本地”，会将验证后的原始声明式 JSON 保存到当前本地目录并刷新本地列表，不自动应用；不会混入简历内容或样式 HTML。下载期间不可更换或重置目录。相同文件不重复写入、不同已有文件不覆盖。下载失败会提示，可再次请求；切换来源会取消尚未开始落盘的待下载动作。

文件菜单现可导出 PDF、DOCX、纯文本和 Markdown。先修复 JSON 与 Schema 错误，再选相应格式和目标路径；导出仅使用当前有效内容，不改写原始 JSON。原生保存窗口会对同名文件询问是否替换；底层写入还会保护源文件，并避免在没有覆盖许可时覆盖刚出现的目标文件。PDF 和 DOCX 使用当前已应用主题，悬停试穿不会改变导出主题；支持单栏的配色、纸张、边距与字体层级，高级布局尚未实现，不支持的主题会明确报错。屏幕预览与 PDF 使用相同的分页、换行、字体和文字坐标，纸张逐页纵向排列；屏幕与 PDF 的抗锯齿可能不同。跨页条目仍可编辑，表单仅在当前操作的一页展开；新增空条目后会直接聚焦表单。

DOCX 的文字为可编辑段落，不是截图；随文档嵌入完整的 Noto 无衬线/衬线字体以覆盖中文和后续编辑，文件约 18 MB，导出在后台完成。纸张背景使用每页重复的底层矢量形状，可随文档打印。Word / LibreOffice 会重新换行分页，字号取半点、600 字重映射为 Word 粗体，因此不保证与 PDF 完全相同；如果阅读器禁用了嵌入字体，仍可能出现字体替换。尚未完成 Microsoft Word 跨平台实机验收。纯文本和 Markdown 不包含主题样式。当前桌面导出固定使用中文模块标题，语言选择尚未接入界面。

主题可为不同模块配置普通、细线、强调线、色底四种标题，以及常规/紧凑条目间距；预览、PDF 和 DOCX 均支持。紧凑模式只收紧留白，不缩字号、不删除内容；切换主题不会改变简历 JSON。配置保存在主题文件的 `sections`，详见主题规范；通过右键定位主题文件后可在外部编辑，重启应用重新载入。时间线、卡片、标签、左右日期与侧栏尚不支持，应用会保留上一个有效主题并在诊断中报告。

单栏主题还支持左对齐或居中的姓名/职业/联系方式，以及行内或逐行排列的联系方式，分别由 `composition.header`（`stacked` / `centered`）和 `composition.contact`（`inline` / `stacked`）控制。长文本会自动换行；居中以内容区为准，摘要和正文仍左对齐，基础信息的编辑入口保持不变。预览、PDF、DOCX 均支持这四种组合；分割页眉和图标联系方式暂不支持。

预览表单打开时会同步当前已应用主题的纸色、文字、输入框边界、光标与选区，无需先切换到 JSON 编辑器；切换主题后重新打开表单也会同步，不改变内容或文件。
