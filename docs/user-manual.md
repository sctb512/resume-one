# Resume One 用户手册

状态：产品正在开发，当前没有正式桌面安装包。源码已支持本地文件/目录打开和只读预览：左侧显示 20 套内置主题，悬停临时预览、点击选中；中央渲染当前 JSON Resume，右侧显示模块及条目数。启动方式为 `cargo run -p resume-one-app`，也可附加一个 JSON 文件或目录路径。macOS 开发应用包可用 `bash packaging/macos/bundle.sh debug` 构建。GUI 编辑、保存、导出、持久设置、在线源和完整主题排版尚未实现；后面的正式版契约不代表这些功能已经交付。

已实现的打开操作：点击右上角“打开”，选择“打开 JSON”或“打开目录”；macOS 快捷键分别为 `⌘O`、`⌘⇧O`，Windows 为 `Ctrl+O`、`Ctrl+Shift+O`。打开目录只列出该目录第一层的普通 `.json` 文件（扩展名不区分大小写，不递归扫描，不跟随目录内符号链接），从顶栏文件名或 `⌘P`/`Ctrl+P` 打开切换器，用上下方向键和 Enter 选择，Esc 或点外部收起。“刷新”重新扫描目录，目录为空时会明确显示空状态；取消或读取失败保留当前简历与主题。

所有当前打开操作均为只读，不修改原文件，也不把主题信息写入 JSON。无文件时显示“示例简历 · 未保存”。现阶段语法或 Schema 无效的文件会显示错误而保留当前预览；源码修复视图将在编辑功能阶段实现。目录和最近状态暂不跨应用重启保存。

正式版启动进入简历预览。用户可打开 `resume.json` 或包含 JSON 文件的目录；`⌘/`（macOS）或 `Ctrl+/`（Windows）在预览与源码间切换。预览中悬停主题可临时试穿，点击才应用；悬停内容可展开编辑表单，`+`/`−` 管理模块与条目，所有编辑支持撤销。源码视图保留右侧模块栏，并支持校验与结构操作。

主题只有一个当前本地目录，可更换或恢复软件默认目录；在线源可添加多个。下载的主题存放在当前本地目录。源码仓库的 `assets/themes/` 目前已有 20 套声明式主题，并内嵌进桌面预览骨架；它们并不等同于已经交付的桌面主题管理界面。应用不提供云同步；若把简历放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

正式导出格式为 PDF、DOCX、纯文本和 Markdown。PDF 应与预览共用分页结果，DOCX 保持可编辑，纯文本和 Markdown 不包含主题样式。功能开放前请以 README 的实现状态为准。
