# Resume One 用户手册

右侧模块栏的新增入口以已选主题声明的 `modules` 为准。简历中已经存在的标准模块仍保留入口供编辑，切换主题不会删除内容。鼠标悬停试穿其他主题时，右侧模块范围不变；点击应用主题后才更新，并清除尚未完成的插入选择。

预览内容编辑：在基本信息或某个条目上停留约 180 毫秒，或直接点击，可打开文档宽度内的表单；Tab 聚焦内容后按 Enter 也可展开，Esc 或表单右上角关闭。表单浮在正文上方，不占用排版高度。当前支持标准普通文本字段，以及成果要点、课程、关键词和项目角色列表。列表内的 `+`、`−` 可在指定位置增删，新增后焦点进入新输入框；每次增删可独立撤销。基本信息表单也支持地址字段和社交账号的逐项编辑、增删；聚焦下方输入框时会自动滚入表单可视范围。输入同步到内存 JSON 和恢复草稿；清空字段会移除该键。邮箱、日期等暂时无效的输入会保留并提示，修复前不能保存或导出。移出纸张且输入框未聚焦时收起；有输入焦点时保持打开。收起后按撤销可回退整次表单编辑，重做可恢复；字段内仍支持正常文本撤销。

状态：产品正在开发，当前没有正式桌面安装包。源码已支持本地文件/目录打开、预览、原生 JSON 编辑、四种桌面导出和本地主题目录设置：左侧初始显示 20 套主题，悬停临时预览、点击选中；中央渲染当前 JSON Resume 或显示源码，右侧始终显示模块及条目数。预览页现可增删标准模块与条目，并撤销、重做；标准文本字段可通过悬停表单编辑。启动方式为 `cargo run -p resume-one-app`，也可附加一个 JSON 文件或目录路径。macOS 开发应用包可用 `bash packaging/macos/bundle.sh debug` 构建。在线源和完整主题排版尚未实现；后面的正式版契约不代表这些功能已经交付。

已实现的打开操作：点击右上角“打开”，选择“打开 JSON”或“打开目录”；macOS 快捷键分别为 `⌘O`、`⌘⇧O`，Windows 为 `Ctrl+O`、`Ctrl+Shift+O`。打开目录只列出该目录第一层的普通 `.json` 文件（扩展名不区分大小写，不递归扫描，不跟随目录内符号链接），从顶栏文件名或 `⌘P`/`Ctrl+P` 打开切换器，用上下方向键和 Enter 选择，Esc 或点外部收起。“刷新”重新扫描目录，目录为空时会明确显示空状态；取消或读取失败保留当前简历与主题。

打开文件或目录不会修改原文件，也不会把主题信息写入 JSON。无文件时显示“示例简历 · 未保存”。语法或 Schema 无效但属于 UTF-8、且不超过 16 MiB 的 JSON 文件会直接进入源码编辑器，原字节保持不变；修复到有效状态后，预览才显示该文件的内容，保存前磁盘文件不变。无法解码的非 UTF-8 文件和超限文件会明确拒绝。目录和最近状态暂不跨应用重启保存。

应用启动进入预览。按 `⌘/`（macOS）或 `Ctrl+/`（Windows）切换预览和 JSON 编辑。切到 JSON 时，左侧主题栏在约 240 毫秒内被中央工作区挤出；返回预览时从左侧拉回并压窄 JSON 工作区。快速反向切换会从当前动画位置继续，右侧模块栏在整个过程中保持原位。JSON 编辑器显示格式化后的副本，不会仅因进入编辑器就改写原始文件。编辑器支持行号、按当前主题配色的语法高亮、软换行、回车缩进，以及在字符串外输入 `{`、`[`、`"` 时自动补全成对符号；单次撤销可同时移除补全的一对符号。直接输入会实时校验 Schema；有错误时底部显示原因和路径，保留最近一次有效预览，错误修复前不能保存。`Ctrl+F` 格式化 JSON；`⌘Z`/`Ctrl+Z` 撤销，格式化也可撤销。搜索改为 `⌘⇧F`/`Ctrl+Shift+F`。

`⌘S`/`Ctrl+S` 保存已有文件；未命名示例会弹出“另存为”。`⌘⇧S`/`Ctrl+Shift+S` 另存为新 `.json` 文件。保存使用文件版本检查：如果磁盘文件在打开后被外部修改，不会静默覆盖。无效 JSON/Schema 内容不能保存。编辑中的内容在应用私有数据目录另存恢复草稿；重新打开同一文件时可选择恢复，恢复后仍遵守原始文件版本检查。切换文件或关闭窗口时，未保存内容会先提示，选择丢弃会删除相应恢复草稿。

预览中，鼠标靠近模块之间或条目之间的插入位置会显示 `+`；悬停已有模块标题或条目会显示对应的 `−`。这些控件不会因悬停而挤动正文。点击模块间 `+` 后，在固定的右侧栏选择要插入的标准模块；也可先在右侧点选尚未存在的模块，再点击纸张上的目标 `+`。点击右侧已有的条目型模块，可在纸张上显示其条目插入点。结构操作只修改当前内存中的 JSON，并保留扩展字段；按 `⌘Z`/`Ctrl+Z` 撤销、`⌘⇧Z`/`Ctrl+Shift+Z` 重做，保存前不会改写磁盘。空模块也会在预览中保留，便于添加第一条内容；切换至 JSON 编辑可看到同步后的结构。JSON 视图的固定右栏现提供模块 `+`/`−`，已有模块的 `+` 会在末尾添加条目；点击已有模块可展开条目列表，在指定位置插入或删除条目。源码编辑器中的这些操作可用文本撤销恢复，撤销回原文件后未保存状态也会清除。JSON 代码行旁的内联结构控件及操作聚焦遮罩尚未交付。

应用仅使用一个当前本地主题目录。首次运行会在系统本地应用数据目录的 `Resume One/themes` 安装 20 套默认声明式主题文件；同名已有文件不会被覆盖。在系统“主题”菜单中可选择其他目录或恢复默认目录，选择后会把缺失的默认主题文件复制到新位置，并载入该目录根部的 `*.theme.json` 及一级子目录中的 `theme.json`。不合规或 ID 重复的文件会被跳过，左侧有可查看的提示；右键主题条目可在文件管理器中定位对应 JSON 文件。目录设置跨重启保存，切换或重置不会删除旧目录文件。在线源和下载尚未接入；未来下载的主题将写入当前本地目录。应用不提供云同步；若把简历或主题目录放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

文件菜单现可导出 PDF、DOCX、纯文本和 Markdown。先修复 JSON 与 Schema 错误，再选相应格式和目标路径；导出仅使用当前有效内容，不改写原始 JSON。原生保存窗口会对同名文件询问是否替换；底层写入还会保护源文件，并避免在没有覆盖许可时覆盖刚出现的目标文件。PDF 使用当前选中的主题，支持单栏的基础配色、纸张、边距与字体层级；高级布局尚未实现，不支持的主题会明确报错。PDF 与屏幕预览目前尚未共用完整分页结果，视觉效果可能不同。DOCX 可编辑，但仍使用基础样式；纯文本和 Markdown 不包含主题样式。当前桌面导出固定使用中文模块标题，语言选择尚未接入界面。
