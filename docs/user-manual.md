# Resume One 用户手册

也可通过系统菜单“主题 → 外观设置…”打开右侧外观栏；它与模块栏的“外观”是同一个入口，在 JSON 输入框获得焦点时也可使用，不会额外打开弹窗。

字体与颜色：点击右侧模块栏标题旁的“外观”，在固定右栏中调整，文档始终可见，不弹出遮挡页面的窗口；“完成”回到模块列表。窄窗口也会为外观栏保留空间而不覆盖纸张。正文与标题分别可选择全部可用的系统字族、本机安装字族、两种内置字体或“跟随主题”。字体列表支持搜索、上下键、Enter 选择及 Esc 返回，只渲染可见行；鼠标放到任意字体整行就试用，移开恢复，点击或 Enter 才确认并保存在本机。系统字体较大时先保留上一有效画面，读取失败保留原设置。点击“安装字体…”可导入 TTF / OTF / TTC / OTC，一次最多 16 个文件；字体只安装在简里本机字体库，不修改系统字体目录或注册表。更改不会写入简历或主题文件，不产生简历未保存标记；试穿其他主题仍保留个人覆盖。JSON 编辑器仍使用等宽字体。

“主题颜色”可设置强调色、纸张、工作区、正文、辅助文字、分隔线及印色。点击色样，在右栏内展开色盘、色相条和常用色；鼠标放在常用色或色盘、色相条的某个位置，页面、顶栏、按钮与面板就实时试用该颜色，移开恢复。点击确认；拖动实时预览，松手才保存，Esc 可撤回本次拖动，再按一次收起色盘。纯悬停不保存设置，导出仍使用已确认的字体和颜色。也可选择“从屏幕取色”，点击目标颜色，按 Esc 取消而不改色；取色不会上传或保存截图。颜色不再要求手填，只有需要时才展开“精确值”，输入 `#RRGGBB`，留空恢复该项默认值。不完整输入不会应用或反复报错，失焦才提示。配色旁“跟随主题”可整体恢复颜色，不影响字体。已应用的设置跨重启保留；预览、缩略图和 PDF/DOCX 使用相同设置，文字颜色可能为保证可读性而校正，TXT/Markdown 不带字体或颜色。在线来源只在主题栏的“管理”中设置，列表中的仓库名称仅用于切换来源。

系统或导入字体会检查实际字形及嵌入标记：缺少中文时使用内置中文备用字体，仍缺字时报告码点；无法嵌入 PDF 或可编辑 DOCX 时会说明原因，不会悄悄换字体。字体文件本身不会随简历 JSON 同步，另一台设备需要自行安装相同字体。字体嵌入标记不等于许可审查结果。Windows 取色、多显示器和 Microsoft Word 仍待原生环境验收。

个人字体选择统一使用该字族的真实正体，不要求所选字体必须有斜体，也不会合成倾斜；这对只提供正体的中文字体同样有效。正文与标题分别覆盖，未覆盖的另一组仍保留主题样式。恢复“跟随主题”会恢复主题原有的斜体和字重，原主题与简历文件始终不变。

本地主题也可自带字体，无需另外安装：把包含 `theme.json` 和字体文件的完整主题文件夹放在所选主题目录下，保留包内相对路径。应用先检查文件是否位于主题内、哈希、字体格式和实际字重，再供预览与 PDF/DOCX 使用；错误主题不会进入可用列表，原因集中在“管理”。这类字体只在当前进程内使用，不进入个人字体列表。同步或复制时需要保留整个主题文件夹；从在线来源下载完整主题包时，应用也会获取并校验声明的字体与许可文件。

保存时若提示“文件正在被其他进程保存”，当前输入与恢复草稿会保留，原文件不会被本次操作覆盖。等待另一个简里窗口或 CLI/Agent 完成写入后再保存；若随后出现版本冲突，请先比较磁盘文件，不能强行覆盖。不要手动删除 `.resume-one.lock` 文件解锁。

带文件路径启动或恢复上次目录时，先显示窗口，再在后台读取。读取较慢时，中央显示等待提示；仍可切换 JSON/预览，右侧模块栏保持原位。点“取消”或按 Esc 可放弃本次读取，保留当前文档；取消后即使系统稍后读完，也不会替换当前内容。Esc 优先关闭已打开的菜单或抽屉。读取期间暂不保存，需先取消或等读取完成；若等待期间修改了当前内容，打开新文件前仍会询问是否丢弃。取消不会终止系统底层读取，最多允许两个未结束的读取；达到上限时请等待后再试。此状态不用于取消已经开始的保存。

macOS 本地验收包将窗口按钮与顶栏合并为一行，拖动品牌区域可移动窗口，双击遵守系统标题栏设置。打开示例时显示“示例预览”，修改后才显示“未保存”。包内 `Contents/MacOS/` 提供两个 CLI，`Contents/Resources/` 附带规范、手册、20 套原生主题、发布构建所带的 67 套社区适配主题和干净的 `example.resume.json`。

检测到恢复草稿时，中央工作区显示“恢复草稿 / 丢弃草稿”，切换预览和 JSON 不再弹出恢复对话框。选择前可查看、切换视图和打开其他文件；编辑、格式化、保存和导出暂时锁定，避免覆盖原草稿。“恢复草稿”保留原版本检查；“丢弃草稿”只删除当前恢复文件，不修改磁盘简历。未选择就关闭或切换文件会保留草稿。

自动展开表单响应基本信息和条目的整个内容区域，包含右侧留白和行间空隙；区域内移动不必重新等待，模块外的纸张空白不会弹出。点击整行和 Tab/Enter 仍可编辑。表单字段区最高 360 逻辑像素，溢出时显示细滚动条，标题与关闭入口始终可见。主题或颜色试用时，应用面板和按钮用约 160 毫秒过渡到新配色，纸张排版直接更新；减少动态效果时不播放这些过渡。

点击应用本地或在线主题后，可在预览工作区用 `⌘Z` / `Ctrl+Z` 撤销、`⌘⇧Z` / `Ctrl+Shift+Z` 重做，与内容操作按发生顺序回退。悬停试穿、再次点击同一主题不产生历史记录；回退只切换外观，不修改简历 JSON，也不重新下载文件。JSON 输入框内的撤销仍用于源码文本。输入法正在组合文字时不会切换视图。

“打开”菜单和系统“文件”菜单均提供“新建简历”（`⌘N` / `Ctrl+N`）。新建保留当前主题和工作目录，进入预览并展开基本信息表单，JSON 初始只有空的 `basics` 对象，不带示例姓名、样式或应用元数据；按保存时再选择文件路径，不自动创建或覆盖文件。当前有未保存编辑或恢复草稿时，先询问是否丢弃；取消保留原输入和草稿。

窗口宽度至少 1280 时显示两侧栏；1024–1279 时通过顶栏“主题”打开主题抽屉，右栏不变；720–1023 时“主题”“模块”分别打开对应抽屉，同时只打开一个。点击遮罩或按 Esc 收起。选定模块后会收起抽屉，方便选择文档插入点；先点文档 `+` 时会自动打开模块抽屉。JSON 模式不显示主题入口，仍能打开模块抽屉。抽屉不会重排文档或影响导出。系统启用减少动态效果时，切换直接完成，不执行平移动画。

JSON 有错误时，预览明确标明正在显示上次有效内容，结构增删暂时禁用；返回 JSON 修复后自动恢复。主题悬停以细线区分，已应用主题使用淡色底和侧标记。顶栏文件、打开、导出与抽屉按钮支持 Tab、Enter/空格操作。

桌面界面沿用 v3 设计的朱印品牌、衬线栏标题和细线列表：顶栏显示文件与保存状态，右侧提供打开、导出；左侧主题用当前简历的第一页生成本机缩略图，悬停停留约 160 毫秒试穿，点击应用。右侧模块采用统一图标与细线列表，仍保留所有增删入口。纸张随窗口等比适配，不改变导出的换行和分页；宽表单的普通字段分两列，长描述通栏，窄表单自动单列。

右侧模块栏的新增入口以已选主题声明的 `modules` 为准。简历中已经存在的标准模块仍保留入口供编辑，切换主题不会删除内容。鼠标悬停试穿其他主题时，右侧模块范围不变；点击应用主题后才更新，并清除尚未完成的插入选择。

预览内容编辑：在基本信息或某个条目的整个内容区域内停留约 140 毫秒（包括无字留白和行间空隙），或直接点击，可打开文档宽度内的表单；已有表单时移向另一条目约 85 毫秒即可切换，并以约 90 毫秒交叉淡化内容。Tab 聚焦内容后按 Enter 也可展开，Esc 或表单右上角关闭。表单以约 160 毫秒纯淡入，采用随主题变化的纸色、细线圆角、轻阴影和柔和输入框；公司/职位及起止日期成组，长描述和链接通栏。表单浮在正文上方，不占用排版高度。当前支持标准普通文本字段，以及成果要点、课程、关键词和项目角色列表。列表内的 `+`、`−` 可在指定位置增删，新增后焦点进入新输入框；每次增删可独立撤销。基本信息表单也支持地址字段和社交账号的逐项编辑、增删；聚焦下方输入框时会自动滚入表单可视范围。输入同步到内存 JSON 和恢复草稿；清空字段会移除该键。邮箱、日期等暂时无效的输入会保留并提示，修复前不能保存或导出。鼠标一旦移出编辑框本身，立即开始约 120 毫秒淡出，即使鼠标仍在纸张内或输入框有焦点；快速移回框内，从当前透明度恢复，不平移或重播入场。输入焦点不会阻止收起，当前可见文字（包括输入法组合文字）会先保留至内存和恢复草稿，原文件不会自动保存。表单消失后不会被下方同一条目立即重新触发，离开该条目再移入即可重新展开；直接点击或键盘打开不受限制。滚动正文会取消尚未展开的候选，稍后轻移鼠标即可重新触发。收起后按撤销可回退整次表单编辑，重做可恢复；字段内仍支持正常文本撤销。

状态：产品正在开发，已有本地验收包，尚未正式发布。源码已支持本地文件/目录打开、预览、原生 JSON 编辑、四种桌面导出、本地主题目录和多来源在线主题浏览：左侧初始显示 20 套原生主题，在线另有 67 套社区适配主题，悬停临时预览、点击选中；中央渲染当前 JSON Resume 或显示源码，右侧始终显示模块及条目数。预览页现可增删标准模块与条目，并撤销、重做；标准文本字段可通过悬停表单编辑。启动方式为 `cargo run -p resume-one-app`，也可附加一个 JSON 文件或目录路径。macOS 本机包用 `bash packaging/macos/bundle.sh release` 构建；`.app/Contents/MacOS/` 内同时包含 `resume-one` 与 `resume-one-theme-migrate`，可在终端用完整路径调用，不会自动加入 PATH。Windows 在安装 Rust 1.99 MSVC、Visual Studio C++ Build Tools 与 Windows SDK 后，可在 PowerShell 用 `cargo build --locked --release -p resume-one-app -p resume-one-cli -p resume-one-theme-migrate` 构建三个 `.exe`；该命令仍待 Windows 实机验收。完整命令见 [README 本地构建](../README.md#本地构建)。社区适配主题由独立仓库维护，正式默认源仍待高保真验收。

macOS 本机包装配后已进行临时签名与严格封签校验。运行 `bash packaging/macos/archive.sh release` 可在 `target/release/` 生成本地评估 ZIP；归档会被解包并再次校验，已有同名 ZIP 不会覆盖。它没有 Developer ID 签名或公证，仅供本机测试，不是可通过 Gatekeeper 的公开分发包。

已实现的打开操作：点击右上角“打开”，选择“打开 JSON”或“打开目录”；macOS 快捷键分别为 `⌘O`、`⌘⇧O`，Windows 为 `Ctrl+O`、`Ctrl+Shift+O`。打开目录只列出该目录第一层的普通 `.json` 文件（扩展名不区分大小写，不递归扫描，不跟随目录内符号链接），从顶栏文件名或 `⌘P`/`Ctrl+P` 打开切换器，用上下方向键和 Enter 选择，Esc 或点外部收起。“刷新”重新扫描目录，目录为空时会明确显示空状态；取消或读取失败保留当前简历与主题。

打开文件或目录不会修改原文件，也不会把主题信息写入 JSON。无文件时显示“示例简历”和“示例预览”，修改后显示“未保存”。语法或 Schema 无效但属于 UTF-8、且不超过 16 MiB 的 JSON 文件会直接进入源码编辑器，原字节保持不变；修复到有效状态后，预览才显示该文件的内容，保存前磁盘文件不变。无法解码的非 UTF-8 文件和超限文件会明确拒绝。成功打开或保存的文件会进入最近列表（最多 12 项）；点击顶栏文件名或按 `⌘P` / `Ctrl+P` 可在当前目录文件及其他最近文件间切换。上次打开的目录在重启后恢复为切换范围，但启动仍直接显示预览，不自动读取最近简历正文或弹出文件列表。路径只保存在本机应用设置中，不写入简历；失效文件会从重启后的最近列表中隐藏。

应用启动进入预览。按 `⌘/`（macOS）或 `Ctrl+/`（Windows）切换预览和 JSON 编辑，也可从系统“视图”菜单触发。切换约 360 毫秒：左侧主题轨道被中央工作区挤出或从左拉入，约 62% 时程开始内容交接，与侧栏收尾重叠；快速反向切换从当前空间和透明度继续，顶栏和右侧模块栏始终保持原位。JSON 编辑器显示格式化后的副本，不会仅因进入编辑器就改写原始文件。编辑器支持行号、主题语法色、软换行、回车缩进，以及在字符串外输入 `{`、`[`、`"` 时自动补全成对符号；单次撤销可同时移除补全的一对符号。直接输入实时校验 Schema；有错误时底部显示原因和路径，保留最近一次有效预览，修复前不能保存。编辑区无标题条或格式化按钮，没有状态时不占用底部空栏。`Ctrl+F` 格式化 JSON；`⌘Z`/`Ctrl+Z` 撤销，格式化也可撤销。搜索为 `⌘⇧F`/`Ctrl+Shift+F`。

`⌘S`/`Ctrl+S` 保存已有文件；未命名示例会弹出“另存为”。`⌘⇧S`/`Ctrl+Shift+S` 另存为新 `.json` 文件。保存使用文件版本检查：如果磁盘文件在打开后被外部修改，不会静默覆盖。无效 JSON/Schema 内容不能保存。编辑中的内容在应用私有数据目录另存恢复草稿；重新打开同一文件时可选择恢复，恢复后仍遵守原始文件版本检查。切换文件或关闭窗口时，未保存内容会先提示，选择丢弃会删除相应恢复草稿。

预览中，鼠标靠近模块之间或条目之间的插入位置会显示 `+`；悬停已有模块标题或条目会显示对应的 `−`。这些控件不会因悬停而挤动正文。点击模块间 `+` 后，正文淡出，右侧可添加的标准模块保持清晰，已存在的模块变淡且不能重复添加；也可先在右侧点选尚未存在的模块，再点击纸张上的目标 `+`，此时正文及右侧其他模块变淡，仅模块插入点保持可操作。点击右侧已有的条目型模块，则仅显示该模块的条目插入点。聚焦淡入淡出约 140 毫秒，右栏不移动；聚焦期间不会触发正文编辑表单。Esc、再次点击已选模块或切换源码可取消待插入状态，取消不修改内容、不占用撤销记录。结构操作只修改当前内存中的 JSON，并保留扩展字段；按 `⌘Z`/`Ctrl+Z` 撤销、`⌘⇧Z`/`Ctrl+Shift+Z` 重做，保存前不会改写磁盘。空模块保留在右侧栏，选中后可添加第一条内容；切换至 JSON 编辑可看到同步后的结构。JSON 视图的固定右栏现提供模块 `+`/`−`，已有模块的 `+` 会在末尾添加条目；点击已有模块可展开条目列表，在指定位置插入或删除条目。源码编辑器中的这些操作可用文本撤销恢复，撤销回原文件后未保存状态也会清除。JSON 代码行旁也提供 `+`/`−`：标准模块的键名行可移除模块，条目开始处可插入或移除该项，列表闭合处可追加条目；模块间 `+` 与固定右栏双向联动，Esc 取消并恢复文本焦点。控件留在独立窄栏，不挤动文字；软换行、滚动和缩放后仍按实际字符位置对齐。若多个目标处于同一视觉行，点击会打开带名称的操作菜单。每次结构编辑可独立撤销，快速连续点击也不合并；撤销后新编辑会清除旧重做分支。语法/Schema 无效或输入法组合输入期间，不显示行旁操作；修复或提交输入后恢复。顶层键重复或结构锚点超过 50,000 时不提供行旁控件，但保留原文供源码修复。

应用仅使用一个当前本地主题目录。首次运行会在系统本地应用数据目录的 `Resume One/themes` 安装 20 套原生主题。升级时，默认目录里的旧预置迁移主题只从「在线 → 迁移版社区主题」浏览，旧文件保留在磁盘。主动下载的离线主题、自选目录中的主题和其他本地主题仍在「本地」显示。点击左侧“管理”，或在系统“主题”菜单选择“管理主题…”，可更换目录或恢复默认目录，选择后会把缺失的默认主题复制到新位置，并载入该目录根部的 `*.theme.json` 及一级子目录中的 `theme.json`。不合规文件会被跳过，原因在管理页查看；不同文件允许有相同 ID，选择按文件身份区分。右键本地主题选择“显示主题文件”可定位 JSON，“主题说明”可查看作者、协议、版本和原始项目；社区包内附许可文件、字体许可及 NOTICE.txt 改编说明，不需要联网即可使用。目录设置跨重启保存，切换或重置不会删除旧目录文件。应用不提供云同步；若把简历或主题目录放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

67 套均为离线声明式适配，全部由独立迁移工具从固定上游来源重新生成。每包的 `MIGRATION.json` 记录纸面样式、模块标题与顺序、字体匹配、排版取舍和样本校验；字体使用真实字重，必要时以独立内部字族解决 DOCX 嵌入冲突，不合成字重。所有迁移包均检查了 PDF 与 DOCX 输出。适配仍可能与原版的动态图形、字段组织和分页不同，不能视为 100% 还原。Rick Osborne 保留原项目、原作者及 CC BY-NC-SA 4.0 正文，保留该许可条件。少数仅声明许可类型的源包附标准许可参考文本，文件内标明它不是上游原件。

本地适配不承诺网页逐像素复刻。字体缺失、图标、动态样式、响应式布局和分页的差异，可查看各包说明。逐套视觉还原度和 Microsoft Word 实机兼容仍需独立验收。主题的排版参数和用户字体、颜色覆盖都不会写回简历 JSON。

主题管理可用 `⌘,`（macOS）或 `Ctrl+,`（Windows）打开，Esc 或“完成”关闭；打开时工作区和右栏不移动。在线来源只在管理内添加、修改、移除，列表旁没有添加源的 `+`。每个来源填写 GitHub 的 `owner/repository`、分支/标签/commit（默认 `main`）、清单路径（默认 `themes/index.json`）和可选的展示名称。名称最多 60 个字符，留空使用来源默认名称；最多 16 个，不允许重复配置。填写草稿不会联网，点击“添加来源”“保存修改”或在输入框内按 Enter 才持久化；取消修改或直接关闭不保存表单草稿。移除来源只删除该配置，不删除本地主题文件。来源与目录设置跨重启保存，互不覆盖；设置文件损坏时会保留原文件并提示，拒绝覆盖。若当前已在浏览在线列表，保存来源变更会重新加载当前来源。默认的「迁移版社区主题」与「原版 JSON Resume」都来自 `sctb512/resume-one-themes` 的 `main` 分支，清单分别为 `migrated-index.json` 和 `originals/index.json`。已有的在线源设置优先，可在管理页补加或修改来源。

「原版 JSON Resume」来源使用上游主题模板。鼠标移到主题上时，应用用当前简历直接渲染 HTML，点击应用，下载后可在本地列表中离线使用。预览可选择文字，在 macOS 使用系统 WebKit，在 Windows 使用 Microsoft Edge WebView2 Runtime。原版 PDF 导出需要本机 Chrome、Edge 或 Chromium。若浏览器位于非标准路径，可在启动应用前将其可执行文件的绝对路径设为 `RESUME_ONE_CHROMIUM`。

原版预览采用主题自身的版式、字体声明和配色。应用外观设置仍会影响简里的界面。原版纸张上的内容由上游 HTML 决定。用右侧模块栏增删模块或条目，预览随即更新。用 `⌘/` 或 `Ctrl+/` 编辑 JSON 后，切回预览会显示最新有效内容。原版 PDF 使用主题自身的打印样式，可编辑 DOCX 使用简里的默认排版，Markdown 和纯文本按简历内容导出。未随主题包提供的在线字体、样式、照片和脚本不会加载，可能影响视觉效果。

默认主题仓库可公开读取。浏览和下载时只请求主题目录及主题文件，渲染使用本机简历。

左侧可切换“本地 / 在线”，在线列表上方点来源名称切换来源（同一来源可重新选择以刷新）。两类主题均用当前 JSON Resume 在中央实时渲染，不下载在线预览图片；悬停仅试穿，点击且通过校验后才应用。内置 20 套并非仅换配色：可按无饰留白、细线、色底、深色纸面、紧凑信息、居中书卷等不同排版气质试穿；「墨序」和「丹朱」使用分栏页眉，但正文仍是单栏。来源和 commit 不同的同名主题相互独立；切换浏览来源、本地列表或本地目录不会清除已应用的在线主题。在线列表预取可视区域附近 20 个主题，悬停优先，最多 3 个后台任务；旧响应不会覆盖新的悬停或选择。网络失败时尝试有效缓存，诊断在管理页查看。未就绪时保留已有有效画面，不显示逐主题提示。右键在线主题选择“下载到本地”，会将验证后的主题包按原始字节保存到当前本地目录并刷新本地列表。已应用主题和简历内容保持独立。下载期间不可更换或重置目录。相同文件不重复写入、不同已有文件不覆盖。下载失败会提示，可再次请求；切换来源会取消尚未开始落盘的待下载动作。

文件菜单现可导出 PDF、DOCX、纯文本和 Markdown。顶栏“导出”菜单底部可选导出标题语言“中文 / EN”，也可在菜单打开时按左/右方向键切换；默认中文，选择在本次运行内保留，影响简里生成的标准模块标题，不翻译简历正文，主题自定义标题仍按主题声明。先修复 JSON 与 Schema 错误，再选相应格式和目标路径；导出仅使用当前有效内容，不改写原始 JSON。原生保存窗口会对同名文件询问是否替换；底层写入还会保护源文件，并避免在没有覆盖许可时覆盖刚出现的目标文件。悬停试穿期间，导出仍以已应用主题为准。声明式主题的 PDF 和 DOCX 支持单栏与左右侧栏的配色、纸张、边距与字体层级，现支持有限的单侧时间线、卡片及标签，不支持的高级构件会明确报错。屏幕预览与 PDF 使用相同的分页、换行、字体和文字坐标，纸张逐页纵向排列；屏幕与 PDF 的抗锯齿可能不同。跨页条目仍可编辑，表单仅在当前操作的一页展开；新增空条目后会直接聚焦表单。

DOCX 的文字为可编辑段落，不是截图；随文档嵌入完整的 Noto 无衬线/衬线字体以覆盖中文和后续编辑，文件约 18 MB，导出在后台完成。纸张背景使用每页重复的底层矢量形状，可随文档打印。Word / LibreOffice 会重新换行分页，字号取半点、600 字重映射为 Word 粗体，因此不保证与 PDF 完全相同；如果阅读器禁用了嵌入字体，仍可能出现字体替换。尚未完成 Microsoft Word 跨平台实机验收。纯文本和 Markdown 不包含主题样式。

主题可为不同模块配置普通、细线、强调线、色底四种标题，以及常规/紧凑条目间距和靠左/靠右日期；预览、PDF 和 DOCX 均支持。靠左日期在标题左侧，标题续行保持对齐；靠右日期在标题首行右侧。过长日期另起一行，地点、机构等其他辅助信息不被挪走。紧凑模式只收紧留白，不缩字号、不删除内容；切换主题不会改变简历 JSON。配置保存在主题文件的 `sections`，详见主题规范；通过右键定位主题文件后可在外部编辑，重启应用重新载入。现支持单侧时间线、可分页卡片、标签和左右侧栏；自定义装饰等未实现配置仍拒绝加载，应用会保留上一个有效主题并在诊断中报告。

单栏正文的页眉可选左对齐、居中或分栏，由 `composition.header` 的 `stacked` / `centered` / `split` 控制；也可用 `composition.preset: split-header` 声明分栏。分栏时姓名和职业在左、联系方式在右，固定按内容区 58% / 42% 分配，两列之间留 14 pt，联系方式靠右；缺少任一侧内容时不保留空列，预览/PDF 在页眉高到单页无法容纳时退回全宽流式排列，避免越界。`composition.contact` 的 `inline` / `stacked` 决定行内连接或逐项换行。摘要默认全宽左对齐，也可通过 `summaryRegion: header` 放在页眉分隔线之前，且不继承居中。左右侧栏预设可用 `headerRegion`、`summaryRegion` 和 `contactRegion` 独立放置身份、摘要及联系方式；同一内容不会重复渲染，两个栏位的基础信息仍编辑同一个 `basics`。预览、PDF 与可编辑 DOCX 使用同一语义。图标联系方式暂不支持。

预览表单打开时会同步当前已应用主题的纸色、文字、输入框边界、光标与选区，无需先切换到 JSON 编辑器；切换主题后重新打开表单也会同步，不改变内容或文件。


## 检查和安装更新

从 GitHub Releases 解压的带版本标记的应用包在启动时会后台检查更新。「打开」菜单可主动检查，macOS 的「Resume One」菜单也有同一入口。检测到新版本后，在菜单选择下载。下载完成时选择「重启并安装」，也可以先保存工作，稍后再从菜单安装。预发布安装可接收后续预发布和稳定版，稳定版只接收更新的稳定版。

应用只读取公开的 Release 元数据和对应平台的安装包。下载文件按 GitHub 提供的 SHA-256 和长度校验，macOS 还会验证应用封签。更新需要应用父目录可写。Windows 请保留解压后的 `Resume One` 目录名称。更新前先保存简历，并将简历目录和自选主题目录放在应用目录之外。成功后旧应用保存在同级 `.resume-one-update-*/previous`；确认新版正常后可自行清理。安装或启动新程序失败时，更新助手尝试恢复旧包，诊断保存在该次更新目录的 `update.log`。
