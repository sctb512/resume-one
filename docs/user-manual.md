# Resume One 用户手册

状态：产品正在开发，当前没有可用的桌面安装包。源码已可启动预览骨架：左侧显示 20 套内置主题，悬停临时预览、点击选中；中央以示例简历或启动参数指定的 JSON Resume 渲染内容，右侧显示模块及条目数。此阶段的打开方式为 `cargo run -p resume-one-app -- /absolute/resume.json`，不会改写文件。若不传文件路径，顶部明确显示“示例简历 · 未保存”。GUI 编辑、导出、目录管理和完整主题排版尚未实现。以下内容固定正式版的用户操作契约，不把尚未实现的功能写成已交付。

正式版启动进入简历预览。用户可打开 `resume.json` 或包含 JSON 文件的目录；`⌘/`（macOS）或 `Ctrl+/`（Windows）在预览与源码间切换。预览中悬停主题可临时试穿，点击才应用；悬停内容可展开编辑表单，`+`/`−` 管理模块与条目，所有编辑支持撤销。源码视图保留右侧模块栏，并支持校验与结构操作。

主题只有一个当前本地目录，可更换或恢复软件默认目录；在线源可添加多个。下载的主题存放在当前本地目录。源码仓库的 `assets/themes/` 目前已有 20 套声明式主题，并内嵌进桌面预览骨架；它们并不等同于已经交付的桌面主题管理界面。应用不提供云同步；若把简历放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

正式导出格式为 PDF、DOCX、纯文本和 Markdown。PDF 应与预览共用分页结果，DOCX 保持可编辑，纯文本和 Markdown 不包含主题样式。功能开放前请以 README 的实现状态为准。
