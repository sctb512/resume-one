# Resume One 用户手册

状态：产品正在开发，当前没有正式桌面安装包。源码已支持本地文件/目录打开、预览和原生 JSON 编辑：左侧显示 20 套内置主题，悬停临时预览、点击选中；中央渲染当前 JSON Resume 或显示源码，右侧始终显示模块及条目数。启动方式为 `cargo run -p resume-one-app`，也可附加一个 JSON 文件或目录路径。macOS 开发应用包可用 `bash packaging/macos/bundle.sh debug` 构建。预览内联表单、模块增删、切换动画、GUI 导出、持久设置、在线源和完整主题排版尚未实现；后面的正式版契约不代表这些功能已经交付。

已实现的打开操作：点击右上角“打开”，选择“打开 JSON”或“打开目录”；macOS 快捷键分别为 `⌘O`、`⌘⇧O`，Windows 为 `Ctrl+O`、`Ctrl+Shift+O`。打开目录只列出该目录第一层的普通 `.json` 文件（扩展名不区分大小写，不递归扫描，不跟随目录内符号链接），从顶栏文件名或 `⌘P`/`Ctrl+P` 打开切换器，用上下方向键和 Enter 选择，Esc 或点外部收起。“刷新”重新扫描目录，目录为空时会明确显示空状态；取消或读取失败保留当前简历与主题。

打开文件或目录不会修改原文件，也不会把主题信息写入 JSON。无文件时显示“示例简历 · 未保存”。当前只能直接打开语法和 Schema 均有效的 JSON Resume；无效文件会显示错误并保留当前预览，直接打开无效文件进行修复尚未实现。目录和最近状态暂不跨应用重启保存。

应用启动进入预览。按 `⌘/`（macOS）或 `Ctrl+/`（Windows）切换预览和 JSON 编辑。切到 JSON 时，左侧主题栏收起，右侧模块栏保持原位；返回预览后主题栏恢复。JSON 编辑器显示格式化后的副本，不会仅因进入编辑器就改写原始文件。编辑器支持行号、按当前主题配色的语法高亮、软换行、回车缩进，以及在字符串外输入 `{`、`[`、`"` 时自动补全成对符号；单次撤销可同时移除补全的一对符号。直接输入会实时校验 Schema；有错误时底部显示原因和路径，保留最近一次有效预览，错误修复前不能保存。`Ctrl+F` 格式化 JSON；`⌘Z`/`Ctrl+Z` 撤销，格式化也可撤销。搜索改为 `⌘⇧F`/`Ctrl+Shift+F`。

`⌘S`/`Ctrl+S` 保存已有文件；未命名示例会弹出“另存为”。`⌘⇧S`/`Ctrl+Shift+S` 另存为新 `.json` 文件。保存使用文件版本检查：如果磁盘文件在打开后被外部修改，不会静默覆盖。无效 JSON/Schema 内容不能保存。编辑中的内容在应用私有数据目录另存恢复草稿；重新打开同一文件时可选择恢复，恢复后仍遵守原始文件版本检查。切换文件或关闭窗口时，未保存内容会先提示，选择丢弃会删除相应恢复草稿。

正式版中，预览会支持悬停内容展开编辑表单，`+`/`−` 管理模块与条目；源码视图也会提供对应结构操作。这些结构化交互目前尚未交付。

主题只有一个当前本地目录，可更换或恢复软件默认目录；在线源可添加多个。下载的主题存放在当前本地目录。源码仓库的 `assets/themes/` 目前已有 20 套声明式主题，并内嵌进桌面预览骨架；它们并不等同于已经交付的桌面主题管理界面。应用不提供云同步；若把简历放在 iCloud Drive 或 OneDrive，文件同步及冲突仍由相应服务负责。主题不会写入 `resume.json`。

正式导出格式为 PDF、DOCX、纯文本和 Markdown。PDF 应与预览共用分页结果，DOCX 保持可编辑，纯文本和 Markdown 不包含主题样式。功能开放前请以 README 的实现状态为准。
