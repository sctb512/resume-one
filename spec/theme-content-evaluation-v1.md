# Theme Content Evaluation v1

**English** · [简体中文](./theme-content-evaluation-v1.zh-CN.md)

The stand-alone migrator can combine its own template IR with an explicit JSON Resume fixture into an unlaid-out content tree. This bounded operation performs no JavaScript execution or CSS computation. It establishes no theme installation, visual acceptance, or migration status.

```sh
resume-one-theme-migrate --source /absolute/theme --inspect --template-entry src/Resume.jsx --dependency /absolute/core --dependency /absolute/utils --fixture /absolute/public-resume.json
```

## Input and Privacy

`--fixture` requires `--inspect` and at least one `--template-entry`. The tool evaluates resume content only with this explicit argument, without searching the source package, desktop state, or home folder. Standard output can contain fixture text. Use a public or de-identified fixture and protect the report.

Require an absolute path to a regular file up to 1 MiB, rejecting symlinks in the path and dot components. Check size and mtime before and after reading. These detect ordinary concurrent modification. Validate with the bundled JSON Resume 1.3.1 schema and record the raw-byte SHA-256 without fetching a remote schema or altering source, theme, or resume data.

## Evaluation

Accept only `resume-one-template-ir-v1` generated by this tool from the same snapshot. Reject syntax errors, unsupported statements, and unknown calls. Only unresolved styles, components, and dynamic URLs may proceed into evaluation, where real lexical bindings, style terminals, component identity, and URL validation are checked independently. Preserve the original blockers and resolved status.

- Initialize module/function const bindings in declaration order, including unused initializers. Building JSX is separate from rendering its children.
- Distinguish undefined/missing, null, false, 0, and empty text. Defaults apply only to undefined. Preserve short-circuit, ternary, and optional-chain semantics, including group boundaries.
- Map dense arrays in order with item, optional index, and lexical local bindings. Reject non-arrays. A JSX Fragment is an element and has undefined length, with no array map or join behavior.
- Join finite scalar values, with null and undefined yielding empty elements. Text templates preserve literal fragments and use ECMAScript number spelling via ryu-js 1.0.3, including -0 as 0. Compound values cannot be serialized into text.
- Strict equality uses supported scalars. Relational comparison handles matching numbers or strings and non-string scalar ToNumber (undefined becomes NaN, null 0, booleans 0 or 1). Any relational comparison with NaN is false. Compare strings by UTF-16 code units. Reject mixed string-number coercion, prototype methods, compound keys, and unsupported property receivers.
- Validate key during element construction and omit it from rendered attributes. Null or boolean children render no text, zero is kept, and objects produce an error. br/hr cannot have children. Use allowlisted native tags and attributes with text treated as data.

## Shared Components

Resolve real declarations from `@jsonresume/core@0.3.6` by module, path, and SHA-256, cross-checked with the dependency snapshots. DateRange and ContactInfo also require exact utils 0.4.0 helper files, exports, and security bridge evidence. Changed source falls outside the supported domain.

| Component | Supported domain |
|---|---|
| Section | Container and child order, bounded id/className. Unknown rest props and polymorphism are rejected. |
| SectionTitle | h2 by default or integer level 1–6, bounded id/className. Icons and unsupported behavior generate errors, and CSS compilation remains separate. |
| DateRange | Valid Gregorian YYYY, YYYY-MM, or YYYY-MM-DD with default short/en-US. A missing end displays only start, whereas an explicit falsy end displays Present. Invalid dates, timestamps, and non-default locale/format/numbering/label are outside the domain. |
| ContactInfo | Preserves email, phone, location, website, profiles order, separators, empty-item rules, and network or username selection. Flat props do not populate basics. Known dangerous protocols lose the href as upstream does. Unsupported URL fallback produces an error. |

DateRange and ContactInfo do not render ignored children. ContactInfo removes only a lowercase http(s) prefix and exactly one terminal slash from the display text. Upstream licenses still apply. Domain errors indicate that equivalence could not be established.

## Imported Styled Declarations

Connect imported const styled definitions by declaration, alias, and base within frozen snapshots. Require the exact const initializer, styled source span, and file and package hashes. Reject collisions, mutation, uninitialized bases, cycles, attrs/helpers, and unsupported bases. Packages still require explicit dependency exports. No Node resolution fallback is inferred.

Record external base-to-derived layers in `externalStyleLayers`, separate from local `styleBindings`. Keep each layer's package, file, fingerprints, declarations, and positions. Terminals must be an allowlisted intrinsic or a verified core component. Keep full CSS and style blockers in the source report. Bound each external chain to 64 levels, 1024 steps, and three seconds, within the evaluator's overall limits.

## Output and Gates

`contentEvaluation.format` is `resume-one-content-evaluation-v1`. Include fixture and entry identities. A successful `result.contentEvaluated: true` and `tree` record elements, attributes, original tags/style bindings, and fixed style roles for that evaluation. Failures report errors and blockers without partial trees or substitute empty nodes. `stylesCompiled`, `layoutCompiled`, `moduleInitializationVerified`, `visualVerified`, and `migrationComplete` remain false. Verify font behavior, cascade, line boxes, margin collapse, pagination, multiple fixtures, and GUI/PDF/DOCX separately.

Bound input depth to 96, reports to 400000 nodes, and fixtures to 50000 nodes and 1 MiB estimated memory. Per entry, cap evaluation at 200000 steps, three seconds, 10000 elements per array, depth 96, and 32 MiB conservative total allocation including containers and copies. Both estimated output size and serialized tree are limited to 8 MiB. The final merged report has a 16 MiB limit. Budget failures never yield truncated success.
